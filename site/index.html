Install

  1. 1 Add the marketplace

    Once, inside Claude Code:

    /plugin marketplace add {{ site.repository }}

  2. 2 Install the CLI

    Each plugin drives a CLI you install yourself. Skills check it's on your PATH and never install anything.

    npm i -g @maschinenlesbar.org/fim-portal-cli

  3. 3 Install the plugin

    Then just ask — Claude picks the right skill.

    /plugin install fim-portal@{{ m.name }}

A few APIs need a free key or account; each plugin's page links to its requirements. Installing a plugin copies its CLI repository and runs npm ci --ignore-scripts there (about 35 MB) — the skills don't use those packages, they call the CLI you installed. Pick up new releases with /plugin marketplace update {{ m.name }}.

For a team or project

Commit this to a project's .claude/settings.json to register the marketplace and enable plugins for everyone working in it: 

{
  "extraKnownMarketplaces": {
    "{{ m.name }}": {
      "source": { "source": "github", "repo": "{{ site.repository }}" }
    }
  },
  "enabledPlugins": {
    "fim-portal@{{ m.name }}": true
  }
}

The tool, not the data

The data comes from the public bodies behind each API, under their own terms — public domain, attribution licences or custom provider terms — documented in DATA_LICENSE.md in each plugin's repository. The plugins and CLIs are dual-licensed AGPL-3.0-or-later or commercial.
